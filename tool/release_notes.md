**Nukefy Client __VERSION__.** Клиент sing-box + Xray + ZAPRET для Windows и Android.

### Что нового в __VERSION__ (поверх 1.2.1)

- **Установщик переписан.** Вместо самосборного exe, который распаковывал себя сам, — обычный установщик Inno Setup: мастер, выбор папки, ярлыки, запись в «Программы и компоненты» с иконкой и версией и штатный деинсталлятор `unins000.exe`. Обновление ставится поверх старой версии, второй «Nukefy» в списке программ не появляется, а `install-options.json` передаёт приложению выбранные галочки (автозапуск, ярлык).
- **Удаление наконец удаляет.** «Удалить» в настройках Windows раньше запускала само приложение: установщик подменял команду удаления ссылкой на клиент, а служебный PowerShell-сценарий внутри приложения падал на первой строке из-за неверного экранирования. Теперь система вызывает настоящий деинсталлятор, а экран «Удалить программу» внутри клиента останавливает свою службу zapret, снимает автозапуск, убирает ярлыки, записи реестра и (по галочке) данные пользователя. Для уже установленных версий путь удаления восстанавливается в первом же запуске.
- **Автозапуск перестал мешать.** Галочка в установщике по умолчанию снята, а запуск при входе в Windows происходит скрыто в трее — окно больше не раскрывается поверх рабочего стола сразу после входа. Аргумент `--tray` теперь действительно обрабатывается.
- **Память.** Ограничен и очищается при сворачивании кэш изображений, убран вечный таймер переразворота окна, меню трея не пересобирается каждый тик, «осиротевшие» после падения копии sing-box/Xray закрываются при старте, MTU по умолчанию снижен с 9000 до 1500 (gvisor-стек держал в памяти буферы под размер MTU), диагностический лог ограничен 512 КБ.
- **Отзывчивость.** Подключение защищено от повторного запуска: двойной клик не поднимает второй туннель и не оставляет вечное «Подключение…». Экран статистики трафика получает данные по фактическому порту Clash API (раньше при занятом 19090 показывал нули). «Конфликт обхода» проверяется не на каждом подключении, а раз в 20 секунд.
- **Нажатия видно.** В прошлой сборке у кнопок были отключены все эффекты, а виджет, который должен был их заменить, так и не появился. Возвращён аккуратный отклик на нажатие, переключение экранов ускорено с 320 до 180 мс, заставка сокращена, фоновая иллюстрация рисуется одним слоем вместо двух, добавлена прокрутка списков мышью.
- **Безопасность.** Установщик обновления и «Дополнения» проверяются по SHA-256 из GitHub, как это уже делалось для ядра, Xray и zapret. Хранилище при ошибке чтения уносится в резервную копию, а не удаляется. На Android отключён облачный бэкап (в нём уезжали ключ шифрования и пароли серверов), убрано неиспользуемое разрешение камеры, «разрешать небезопасный TLS» больше не включено по умолчанию.
- **Мелочи.** Две ошибки подключения больше не показываются по-русски в английском интерфейсе; версия в README, pubspec и экране «О программе» наконец совпадает.

### Что скачать

- **Windows:** `NukefyClient-__VERSION__-x64.exe` — установщик. Ставится поверх прошлой версии, данные и подписки сохраняются.
- **Android:** `NukefyClient-__VERSION__.apk` — обновление ставится без удаления приложения.

Хэши файлов лежат в `SHA256SUMS.txt` рядом с релизом.
