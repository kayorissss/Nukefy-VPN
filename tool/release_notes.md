**Nukefy Client __VERSION__.** Клиент sing-box + Xray + ZAPRET для Windows и Android.

### Что нового в __VERSION__

- **Установка больше не падает с ошибкой 740** («Запрошенная операция требует повышения»). Клиент запускается после установки через оболочку, которая поднимает UAC как положено; раньше установщик пытался стартовать exe напрямую и получал отказ. Заодно установщик больше не наследует старую папку установки `Nukefy VPN`.
- **Окно сразу развёрнуто.** Разворот вызывался до того, как окно появилось, и Windows его отбрасывал — отсюда «среднее окно». Теперь порядок правильный (показать → развернуть → проверить), а в заголовке появилась кнопка «развернуть/восстановить», которой не было совсем.
- **Левое меню пересобрано**: одинаковые строки для всех разделов, небольшие подписи групп, акцентный маркер у активной страницы, наведение и курсор-рука, чистые отступы. Плашка «Дополнения» убрана — страница осталась в меню «все страницы» (три точки в заголовке меню).
- **Страница серверов выровнена**: заголовок и поиск больше не делят строку 1:2, поиск ограничен по ширине, на узком окне уезжает под заголовок, список центрируется по той же сетке, что и настройки.
- **Карта мира на главной ведёт себя спокойно**: до подключения она просто стоит, подлёт к стране и свечение метки — только при активном туннеле, точки мельче.

### Что скачать

- **Windows:** `NukefyClient-__VERSION__-x64.exe` — установщик Inno Setup. Ставится поверх прошлой версии, данные и подписки сохраняются, удаление штатное через «Программы и компоненты».
- **Android:** `NukefyClient-__VERSION__.apk` — обновление ставится без удаления приложения.

Хэши файлов лежат в `SHA256SUMS.txt` рядом с релизом.
