**Nukefy Client __VERSION__ — бета.** Свой клиент sing-box + Zapret для Windows и Android.

### Что скачать

| Файл | Что это |
|---|---|
| `NukefyClient-__VERSION__-x64.exe` | Единственный файл для Windows: брендированный установщик с выбором языка, параметров установки и прогрессом. |
| `NukefyClient-__VERSION__.apk` | Android. В имени нет лишнего суффикса `android`. |
| `SHA256SUMS.txt` | Контрольные суммы файлов релиза. Проверить скачанное: `certutil -hashfile NukefyClient-__VERSION__-x64.exe SHA256` — полученный SHA-256 должен совпасть со строкой для этого файла. |

### Удаление

«Удалить» в Параметрах Windows (или в Панели управления) открывает собственное окно Nukefy с галочками: служба zapret, автозапуск, данные и само приложение. Папку вручную удалять не нужно.

Подписки и настройки сохраняются при обновлении. При удалении можно отдельно оставить данные. Общий драйвер WinDivert остаётся, потому что может использоваться другими программами.
