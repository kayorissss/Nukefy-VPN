**Nukefy Client __VERSION__.** Клиент sing-box + Xray + ZAPRET для Windows и Android.

### Что нового в __VERSION__

- **Настройки пересобраны с нуля по порядку.** Одна колонка по центру вместо двух колонок, где карточки разной высоты соседствовали как попало. Порядок теперь человеческий: «Подключение» → «Запуск и окно» → «Подписки» → ядра → «Дополнительно» (свёрнуто по умолчанию). Баннер обновлений уехал в «О приложении», переключатели разделов стали компактными пилюлями вместо полосы во всю ширину.
- **Карта мира на главной.** Фоном — контуры континентов, собранные из точек (Natural Earth). При подключении камера плавно подлетает к стране сервера, у метки загорается свечение, и на этом всё замирает: карта не пульсирует и не жжёт батарею.
- **Пинг перестал врать.** Раньше зелёные миллисекунды означали лишь «TCP-порт ответил» — мёртвый или неверно настроенный сервер тоже отвечает рукопожатием. Теперь результат настоящей проверки через туннель запоминается для сервера: либо галочка «проверено», либо честная плашка «нет трафика» вместо красивого числа.
- **Тише и плавнее.** Убран двойной обмер карточек при каждой раскладке, страница настроек больше не пересобирается каждую секунду из-за статуса туннеля, фоновый арт вынесен в отдельный слой-кэш и с главной убран совсем (там теперь карта).
- **Установщик** больше не кладёт в папку программы README.md.

### Что скачать

- **Windows:** `NukefyClient-__VERSION__-x64.exe` — установщик Inno Setup. Ставится поверх прошлой версии, данные и подписки сохраняются, удаление работает штатно через «Программы и компоненты».
- **Android:** `NukefyClient-__VERSION__.apk` — обновление ставится без удаления приложения.

Хэши файлов лежат в `SHA256SUMS.txt` рядом с релизом.
