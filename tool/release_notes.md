**Nukefy Client __VERSION__ — бета.** Свой клиент sing-box + Zapret для Windows и Android.

### Что скачать

| Файл | Что это |
|---|---|
| `NukefyClient-__VERSION__-Setup-x64.exe` | Обычная установка. Своё окно установщика: выбор языка, галочки, прогресс, тёмный стиль приложения. Ставится в `Program Files\Nukefy Client`. |
| `NukefyClient-__VERSION__-Portable-x64.exe` | Без установки. Один файл: при первом запуске распаковывается в `%LOCALAPPDATA%\NukefyVPN`. |
| `NukefyClient-__VERSION__.apk` | Android. |
| `SHA256SUMS.txt` | Контрольные суммы файлов выше. Проверить скачанное: `certutil -hashfile NukefyClient-__VERSION__-Setup-x64.exe SHA256` — значение должно совпасть со строкой из файла. |

### Удаление

«Удалить» в Параметрах Windows (или в Панели управления) открывает **наше** окно удаления с галочками: что убрать — обход, автозапуск, данные, саму программу. Папку руками удалять не нужно, но и нельзя: часть файлов лежит в системной папке.

Подписки, настройки и журналы хранятся отдельно от программы и **сохраняются при обновлении**.
