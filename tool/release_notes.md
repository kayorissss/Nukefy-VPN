## Nukefy Client __VERSION__ — обновление по вашим отзывам

### Главное
- **Подключение больше не зависает.** Кнопка отключения раньше срабатывала только после полной остановки ядер — теперь состояние меняется мгновенно, а зависшая попытка подключения сама отменяется за 30 секунд с понятной ошибкой вместо вечного «подключение…».
- **Честный пинг.** Единица теперь «мс» при русском языке (было «ms»), измерения старше 30 минут не выдаются за свежие, а после подключения показывается реальная задержка через туннель — как в Happ, а не оценка по рукопожатию.
- **Настоящая статистика для Xray.** При xray-proxy сессиях счётчики трафика берутся из самого ядра Xray — больше никаких вечных нулей.

### Интерфейс
- Настройки: плашки больше не перекрывают друг друга на широких окнах (добавлен автоматический тест раскладки на 1280/1500/1920 px).
- Уведомления живут только на главной странице; тосты выезжают справа.
- Окно приложения сразу открывается развёрнутым на весь экран.
- В шапке бокового меню убран лишний значок — осталась одна кнопка сворачивания справа.
- В установщике убран лишний значок в шапке; переключатель RU/EN справа, кликабельный.
- Страница ZAPRET получила статус-шапку: состояние, активная стратегия, версия ядра и отметка рекомендованной стратегии; когда обход работает, шапка подсвечена.
- Пункты выпадающих меню снова читаемы во всех визуальных темах.

### Ядра
- «Обновить Xray» теперь ставит **самый свежий релиз XTLS, включая пререлизы** (сейчас это v26.10.10; стабильная ветка отставала на месяцы — v26.3.27).

### Как проверить скачанный файл

Скачайте `SHA256SUMS.txt`, откройте PowerShell в папке загрузок и выполните:

```
Get-FileHash .\NukefyClient-__VERSION__-x64.exe -Algorithm SHA256
```

Полученная строка должна совпасть со строкой `NukefyClient-__VERSION__-x64.exe` из `SHA256SUMS.txt` (для Android — с суммой APK). Если строки разные, файл скачался с ошибкой или его подменили: удалите его и скачайте заново с этой страницы.

Подписки и настройки сохраняются при обновлении.
