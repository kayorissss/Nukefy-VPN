# Nukefy VPN

Клиент sing-box для Android и Windows. Поддерживаются VLESS Reality, VMess, Trojan, Shadowsocks, Hysteria2, TUIC, WireGuard и AmneziaWG.

Версия: **2.1.1**

Автор: **@kayorisan**

## Что нового в 2.1.1

- Незаметная иконка «Notes» (Android) — приложение выглядит как заметки.
- Разбор больших подписок вынесен в фоновый изолят — интерфейс не замирает при обновлении.

## Что нового в 2.1.0

- **Тест скорости**: загрузка, отдача, пинг и джиттер на живой шкале, история результатов (Статистика → Тест скорости).
- **Цвет акцента**: 7 палитр (бирюза, фиолет, малина, роза, синий, изумруд, янтарь) — в Настройках, сохраняется.
- **Иконка приложения** (Android): 5 вариантов, переключение без переустановки.
- Плитка в шторке и действия из уведомления теперь синхронизируют состояние с приложением; открытие уже запущенного приложения из плитки подключает VPN.
- Telegram-прокси: копирование ссылки долгим нажатием или кнопкой.
- Исправлена вёрстка «Представляться как» в настройках подписок.
- Производительность: большие подписки показываются страницами по 40, массовая проверка пинга больше не подвешивает интерфейс.
- Проверка трафика после подключения: если сервер не пропускает данные, приложение говорит об этом прямо; XHTTP-серверы помечаются как неподдерживаемые sing-box.

## Что нового в 2.0.0

- **Android подключается.** Ядро sing-box встроено в APK как `libbox.aar` (собирается в GitHub Actions из sing-box 1.12). Ошибки `Permission denied` при запуске ядра больше нет — системный VPN работает на современных Android.
- **Windows подключается.** Конфигурация переведена на rule actions sing-box 1.11+: убраны `sniff`/`domain_strategy` из inbound, ядро 1.13+ больше не падает с `legacy inbound fields deprecated`.
- **Новый логотип и иконка**, шрифты Unbounded (заголовки, вкладки, кнопки, цифры) и Montserrat (текст), анимации переходов, плавающая нижняя панель с подписями капсом, прозрачные системные панели (edge-to-edge).
- **Главный экран:** карточка сервера открывает быстрый выбор — один тап и подключение. Кнопка подключения крупнее, ошибки объясняются словами.
- **Серверы:** тап по серверу подключает сразу, долгое нажатие — меню. Фильтры-чипы убраны, JSON серверов из подписки не редактируется. Иконка пинга заменена на аккуратный бейдж, «Обновить» — на иконку.
- **Глушилки:** сначала только большая кнопка «Проверить сеть», результаты появляются анимированно с иконками сервисов и вердиктом.
- **Настройки** перегруппированы: Telegram-прокси сверху, «Какие приложения идут через VPN» с объяснением, кнопка «В шторку» (Quick Settings), блок «Антиглушилка» убран, DNS с пояснением, выпадающие списки в стиле приложения.

- **Обновления и ядро** скачиваются на полноэкранной странице с анимацией; после установки ядра видно состояние «Установлено».
- **Уведомление** при подключении: иконка, имя сервера, кнопки «Пинг» и «Отключить». Плитка в шторке включает и выключает VPN.
- **Светлая тема** переработана: контрастный текст, приглушённые акценты.

## Скачать

Готовые файлы лежат в [релизах](https://github.com/kayorissss/Nukefy-VPN/releases/latest):

- **NukefyVPN-android.apk** — поставить на телефон. Если Android ругается, разрешите установку из этого источника.
- **NukefyVPN-windows-x64.zip** — распаковать и запустить `nukefy_vpn.exe`.

На Windows после установки откройте Настройки и скачайте ядро в карточке «Ядро sing-box», иначе VPN не запустится. На Android ядро уже внутри APK.

Первый запуск пустой: нет предустановленных подписок. Ссылку можно вставить, набрать или отсканировать QR. Данные остаются на устройстве — зашифрованный Hive, без аналитики, Firebase и внешних логов. Подписки качаются только с URL, который указал пользователь.

## Возможности

- Главный экран с кнопкой питания, статусом, таймером и живым трафиком
- Серверы: буфер, ручной ввод, QR, файлы `.json` / `.txt` / `.conf` / Clash YAML, подписки
- Глушилки: проверка порта 443 и вердикт — белые списки, помех нет или сеть не отвечает
- Пинг, сортировка, фильтр по стране, протоколу и доступности
- Антиглушилка: мосты, фрагментация TLS, MUX, приоритет мостов
- Статистика сессии и журнал последних подключений
- Маршрутизация: весь трафик, только заблокированные, всё кроме РФ, свои правила
- DNS DoH/DoT, локальный SOCKS `10808` и HTTP `10809`, TUN `172.19.0.1/30`
- На Android: VpnService, уведомление с отключением, автозапуск, плитка быстрых настроек, раздельное туннелирование, установка обновления
- На Windows: трей, сворачивание в трей, автозапуск через реестр
- Проверка обновлений по GitHub Releases, с прогрессом, размером и оставшимся временем
- Кнопка Telegram Proxy в настройках

## Сборка

Нужен Flutter **3.47** (Dart `>=3.13`) и JDK 17. Самим собирать не обязательно: файлы появляются в релизе сами.

```bash
flutter pub get
flutter test
flutter build apk --release
flutter build windows --release
```

Android: `minSdk 21`, `targetSdk 34`, `applicationId` `com.nukefy.vpn`. Если движок Flutter или плагин откажется от API 21, в `android/app/build.gradle.kts` замените `minSdk = 21` на `minSdk = maxOf(21, flutter.minSdkVersion)`.

Релизный APK сейчас подписывается debug-ключом, чтобы `flutter build apk` проходил без keystore. Для публикации замените `signingConfig` в `android/app/build.gradle.kts`.

## Ядро

Конфиг — sing-box **1.12**. На Windows ядро и `wintun.dll` скачиваются из официального релиза SagerNet/sing-box кнопкой в настройках и запускаются как `sing-box.exe run -c`. TUN может потребовать запуск от администратора. Закрытие окна сворачивает приложение в трей, если это не выключено в настройках.

На Android системный VPN работает только через `libbox.aar` в процессе приложения. Релизный workflow собирает его сам (job `libbox`, sing-box 1.12) и кладёт в `android/app/libs/`. Локально: `tool/build_libbox.sh`. Без AAR приложение собирается со стабом `nolibbox` и честно сообщает, что ядро отсутствует.

## Обновления

Кнопка «Проверить обновления» смотрит `https://api.github.com/repos/kayorissss/Nukefy-VPN/releases/latest`. Если релиза нет (404), это считается «вы уже на последней версии». Если версия новее и в релизе есть `.apk` или Windows-файл, показывается окно с процентами, скоростью и оставшимся временем, затем файл скачивается.
