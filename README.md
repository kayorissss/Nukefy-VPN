# Nukefy Client

VPN-клиент для Android и Windows на двух ядрах: **sing-box** (основное) и
**Xray-core** (для серверов с транспортом XHTTP/SplitHTTP, которого в
sing-box нет и в актуальной версии v1.14 не появилось). Поддерживаются
VLESS Reality, VMess, Trojan, Shadowsocks, Hysteria2, TUIC, WireGuard и
AmneziaWG.

Автор: **@kayorisan**

## Скачать

Готовые файлы лежат в [релизах](https://github.com/kayorissss/Nukefy-VPN/releases/latest):

- **NukefyClient-Setup.exe** — установщик для Windows. Сам закроет
  запущенную программу, удалит старую «Nukefy VPN» (и её папку, и запись
  деинсталлятора) и поставит Nukefy Client на её место: второй копии на
  компьютере не останется. Устанавливается без прав администратора.
- **NukefyClient-windows-x64.zip** — тот же клиент без установщика:
  распаковать и запустить `nukefy_vpn.exe`.
- **NukefyClient-android.apk** — поставить на телефон. Пакет
  (`com.nukefy.vpn`) и подпись не менялись, поэтому APK встанет поверх
  старой версии со всеми серверами и настройками.

## Быстрый старт

1. Откройте приложение и нажмите **«Автонастройка»** (на компьютере — слева
   внизу, на телефоне — плашка «С чего начать» на главной). Она скачает
   ядро, проверит серверы настоящим пингом и выберет быстрый.
2. На вкладке **«Серверы»** добавьте подписку или ссылку на сервер
   (кнопки сверху: вставить, ввести, QR, файл). У подписки можно указать
   **зеркала** — запасные адреса: если основной не отвечает, приложение
   само обновится через зеркало и покажет, какое сработало.
3. Нажмите на сервер, затем на большую кнопку питания на главной.

Серверы с транспортом **XHTTP (SplitHTTP)** запускаются через ядро Xray:
скачайте его один раз в **«Дополнениях»** или той же автонастройкой.
Смешивать не нужно — клиент сам выбирает движок по серверу и честно пишет
на главной, какой движок работает. В режиме Xray доступен локальный прокси
SOCKS `10808` / HTTP `10809`; системный TUN для таких серверов выполняет
sing-box, поэтому для TUN выбирайте сервер с TCP/Reality, WS, gRPC или
HTTPUpgrade.

## Что внутри

- Главный экран: кнопка питания, статус, таймер сессии и живая скорость
  из ядра (не рисованная).
- Уведомления — плашками в правом верхнем углу и в истории за колокольчиком:
  ошибки подключения больше не прилипают красным текстом под кнопкой.
- На компьютере: боковое меню (сворачивается кнопкой и перетаскиванием
  мышью за край), своя строка заголовка со свернуть/развернуть/закрыть,
  старт сразу в развёрнутом окне.
- **Анализ соединений**: живые соединения ядра, реальная задержка внутри
  туннеля и проверка внешнего IP через прокси.
- Серверы: буфер, ручной ввод, QR, файлы `.json` / `.txt` / `.conf` /
  Clash YAML, подписки с зеркалами, настоящий TCP-пинг (после подключения
  заменяется задержкой в туннеле), сортировка и фильтры.
- Маршрутизация: весь трафик, только заблокированные, всё кроме РФ, свои
  правила («белые списки»). Удалённые rule-set качаются напрямую, а если
  ядро с ними не стартовало, клиент сам повторяет запуск на встроенных
  правилах — режим не умирает молча.
- DNS DoH/DoT, локальный SOCKS `10808` и HTTP `10809`, TUN `172.19.0.1/30`.
- На Android: VpnService, уведомление с отключением, автозапуск, плитка
  быстрых настроек, раздельное туннелирование, установка обновления
  поверх старой версии.
- На Windows: трей, сворачивание в трей, автозапуск через реестр,
  прогресс загрузки на иконке панели задач.
- Обновления по GitHub Releases: окно загрузки показывает проценты,
  размер, скорость и оставшееся время; Windows-установщик обновления
  запускается сам и закрывает старую версию.

Первый запуск пустой: предустановленных подписок нет. Данные остаются на
устройстве — зашифрованный Hive, без аналитики и внешних логов. Подписки
качаются только с адресов, которые указал пользователь.

## Сборка

Нужен Flutter **3.47** (Dart `>=3.13`) и JDK 17. Самим собирать не
обязательно: файлы появляются в релизе сами.

```bash
flutter pub get
flutter test
flutter build apk --release
flutter build windows --release
```

Windows-установщик собирается Inno Setup 6 из `installer/NukefyClient.iss`
(в релизном workflow это делается автоматически).

Android: `minSdk 21`, `targetSdk 34`, `applicationId` `com.nukefy.vpn`.
Релизный APK подписывается debug-ключом, чтобы сборка проходила без
keystore; подпись и пакет стабильны между версиями, поэтому обновления
ставятся поверх.

## Ядра

Конфиг sing-box — формат **1.12+**; ядро скачивается из официального
релиза SagerNet/sing-box кнопкой в «Дополнениях». На Windows рядом нужен
`wintun.dll` (приходит в том же архиве), TUN может потребовать запуск от
администратора. Перед стартом конфиг проверяется через
`sing-box check`, поэтому реальная ошибка ядра показывается сразу, а не
маскируется под «подключение».

Xray-core скачивается из официального релиза XTLS/Xray-core туда же.
Транспорт XHTTP в sing-box отсутствует (проверено по исходникам v1.14:
доступны только http/ws/quic/grpc/httpupgrade), поэтому такие серверы
обслуживает Xray с тем же локальным прокси и реальной статистикой через
его Stats API.

На Android системный VPN работает через `libbox.aar` в процессе
приложения. Положите архив в `android/app/libs/libbox.aar` и пересоберите.
Как собрать AAR: `tool/build_libbox.sh`. Без AAR приложение собирается, но
честно сообщает, что TUN недоступен; скачанные бинарники sing-box и Xray
работают как локальный прокси, если устройство разрешает их запуск.
